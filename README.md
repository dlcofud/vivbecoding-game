# vivbecoding-game — 아무말 컴파일러

말도 안 되는 단어 카드를 스크래치식 블록에 끼워 문장을 만들면, 그 문장이 그대로 **바이브 코딩 명령어**가 되어 게임으로 빌드되는 놀이입니다.

> 예: "월급 밀린 용이 구청 민원실에서 매국노처럼 김밥을 던진다. 팀장님에 닿으면 둘로 분열한다. 점수는 한숨으로 센다."

## 노는 법

청혼 게임처럼, **무작위로 받은 단어로 어떻게든 말이 되는 문장을 만드는 것**이 이 게임의 재미입니다.

1. **손패 받기**: 무작위 카드 9장을 받습니다. 칸에 딱 맞는 카드가 있다는 보장은 없어요. "손패 다시 뽑기"는 3번까지.
2. **아무 칸에나 놓기**: 카드는 어느 칸에든 놓을 수 있어요. 대신 칸이 원하는 품사가 아니면 **연결 토큰**이 붙어 억지로 이어집니다.
   - 행동 칸에 "팀장님"(명사) → "팀장님**이 된다**"
   - 주인공 칸에 "랩을 한다"(동사) → "랩을 하**는 자**"
   - 방식 칸에 "붕어빵"(명사) → "붕어빵**처럼**"
3. **컴파일 검사**: 빈칸이 있거나 연결 토큰을 2개보다 많이 쓰면 빌드 버튼이 안 눌려요.
4. **Claude 심사**: 깐깐한 심사위원이 주인공·무대·움직임·장애물·결과·점수 단위가 하나의 게임으로 이어지는지 봅니다. 말이 안 되면 이유와 함께 **탈락**하고 게임이 만들어지지 않아요. 통과하면 창의력 점수와 함께 게임이 빌드됩니다.
5. **플레이·다운로드**: 무대에서 바로 하고, 한 파일짜리 HTML로 내려받을 수 있어요.

## 실행

`index.html`을 브라우저로 열면 됩니다.

- **Claude Artifact 안에서 열 때**: Claude 심사와 빌드가 됩니다.
- **그 밖의 곳(로컬 파일, GitHub Pages 등)에서 열 때**: Claude 심사는 안 되고, "0 토큰" 모드(문법 검사만)로 연습할 수 있어요.

빌드 방식과 사용량은 [docs/TOKEN_SAVING.md](docs/TOKEN_SAVING.md)를 보세요.

## 파일 구조와 담당

| 파일 | 담당 | 내용 |
|---|---|---|
| `js/words.js` | 블록 조합 | 카테고리와 단어 카드 목록 |
| `js/blocks.js` | 블록 조합 | 손패(무작위), 블록 모양, 아무 칸에나 놓기, 문장 만들기 |
| `css/blocks.css` | 블록 조합 | 카드·블록·빈칸 스타일, 카테고리 색 |
| `js/converter.js` | 토큰 변환기 | 토큰 변환기 화면, Claude 빌드, 무대, 게임 다운로드 |
| `js/grammar.js` | 토큰 변환기 | 칸별 품사 규칙, 연결 토큰, 컴파일 검사 |
| `js/token-saver.js` | 토큰 변환기 | 심사 명령어, 빌드 방식·모델, 토큰 어림, 저장본, 누적 사용량 |
| `js/word-meta.js` | 토큰 변환기 | 단어 해석표 (0 토큰 모드) |
| `js/game-template.js` | 토큰 변환기 | 게임 엔진: 설정만으로 도는 엔진과 규칙 코드용 틀 |
| `docs/TOKEN_SAVING.md` | 토큰 변환기 | 토큰 절약 방법과 쓸 수 있는 오픈 소스 정리 |
| `css/converter.css` | 토큰 변환기 | 토큰 변환기·무대 스타일 |
| `index.html` | 공용 | 빈 틀. 두 부분이 들어갈 자리(`#workbench`, `#converter`)만 있음 |
| `js/main.js` | 공용 | 두 부분을 화면에 붙이고 연결 (4줄) |
| `css/base.css` | 공용 | 페이지 틀, 패널, 버튼, 공용 색 |

각자 자기 담당 파일만 고치면 서로 충돌이 나지 않습니다. 공용 파일을 고쳐야 하면 미리 말해 주세요.

## 두 부분이 주고받는 약속

토큰 변환기는 블록 쪽을 `window.Blocks`로만 읽습니다. 아래 함수의 **이름과 돌려주는 모양**만 지키면, 블록 쪽은 카테고리를 늘리든 블록 모양을 바꾸든 자유입니다.

| 함수 | 돌려주는 것 |
|---|---|
| `Blocks.mount(el)` | 작업대를 `el` 안에 그림 |
| `Blocks.onChange(fn)` | 카드가 움직일 때마다 `fn()` 호출 |
| `Blocks.filledCount()` / `Blocks.total()` | 채운 칸 수 / 전체 칸 수 |
| `Blocks.isComplete()` | 다 채웠으면 `true` |
| `Blocks.sentence()` | 완성 문장 (문자열) |
| `Blocks.sentenceParts()` | `[{text, slot?:{key, label, color, filled, word, cardCat, glue, bad}}]`: 연결 토큰까지 붙은 문장 조각 |
| `Blocks.guide()` | `["주인공 (플레이어가 조종): 매국노", ...]` — 명령어의 해석 가이드 줄 |
| `Blocks.title()` | 게임 이름으로 쓸 짧은 단어 |

이 약속을 바꿔야 하면 두 사람이 같이 정하고, 위 표도 함께 고쳐 주세요.

## 같이 작업하는 법

```bash
git pull                      # 시작 전에 항상 최신으로
git switch -c blocks/카드추가   # 자기 작업용 브랜치
# ... 담당 파일 수정 ...
git add -A && git commit -m "카드 추가"
git push -u origin blocks/카드추가
```

GitHub에서 Pull Request를 열고 상대가 확인한 뒤 `master`에 합칩니다.

## 단어 카드 추가

`js/words.js`의 카테고리별 `words` 배열에 단어를 넣으면 됩니다.
