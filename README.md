# vivbecoding-game — 아무말 컴파일러

말도 안 되는 단어 카드를 스크래치식 블록에 끼워 문장을 만들면, 그 문장이 그대로 **바이브 코딩 명령어**가 되어 게임으로 빌드되는 놀이입니다.

> 예: "월급 밀린 용이 구청 민원실에서 매국노처럼 김밥을 던진다. 팀장님에 닿으면 둘로 분열한다. 점수는 한숨으로 센다."

## 노는 법

1. **카드 받기** — 주인공, 무대, 방식, 행동, 장애물, 결과, 점수 단위 7개 카테고리마다 아무말 카드를 2장씩 받습니다.
2. **블록 채우기** — 카드를 누르고 같은 색 칸을 누르거나, 끌어다 놓습니다. 칸의 카드를 다시 누르면 손패로 돌아옵니다. "패 바꾸기"는 3번까지.
3. **문장 → 토큰** — 블록이 한 문장으로 이어지고(조사 자동 처리), 토큰 조각과 대략적인 토큰 수가 표시됩니다.
4. **게임 만들기** — 최종 명령어를 Claude에 보내 한 파일짜리 HTML 게임을 만들고, 무대에서 바로 플레이합니다.

## 실행

`index.html` 하나로 동작합니다. 브라우저로 열면 됩니다.

- **Claude Artifact 안에서 열 때**: "토큰 연결하고 게임 만들기" 버튼이 Claude를 직접 불러 게임을 빌드합니다.
- **그 밖의 곳(로컬 파일, GitHub Pages 등)에서 열 때**: Claude 연결이 없으므로 "명령어 복사"로 명령어를 복사해 원하는 바이브 코딩 도구(Claude, Claude Code 등)에 붙여 넣으세요.

## 단어 카드 추가

`index.html`의 `CATS` 객체에서 카테고리별 `words` 배열에 단어를 넣으면 됩니다.
