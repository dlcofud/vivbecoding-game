# 토큰 절약 가이드

게임 한 판을 빌드할 때 드는 Claude 사용량은 두 가지입니다.

| | 내용 | 이 게임에서 크기 |
|---|---|---|
| **입력 토큰** | 우리가 보내는 명령어 | 약 450~500 |
| **출력 토큰** | Claude가 써 주는 게임 코드 | 전체 HTML이면 약 3,500~6,500 |

출력이 입력보다 열 배쯤 크고, 보통 출력 토큰이 입력 토큰보다 단가도 높습니다. 그래서 **명령어를 줄이는 것보다 받는 코드를 줄이는 게 훨씬 효과가 큽니다.**

> 숫자는 모두 `TokenSaver.count()`의 어림값입니다. Claude 토크나이저는 브라우저용으로 공개돼 있지 않아서, 정확한 값은 Anthropic의 count_tokens API로만 알 수 있어요.

---

## 이미 들어가 있는 장치

### 1. 게임 틀 (`js/game-template.js`) — 효과 가장 큼

캔버스 크기 맞추기, 게임 루프, 키보드·터치 입력, 상단 HUD, 게임 오버와 다시하기를 틀이 미리 갖고 있습니다. **절약 모드**에서는 Claude가 아래 모양의 `GAME` 객체만 씁니다.

```js
const GAME = {
  title, unit, hint, bg,
  init(s, E) {},          // 새 판 준비
  update(s, dt, E) {},    // 매 프레임 규칙
  draw(ctx, s, E) {}      // 그리기
};
```

- 받는 코드: 약 3,500~6,500 → **약 900~1,800 토큰**
- 덤으로 게임이 덜 깨집니다. 입력·게임 오버 같은 공통 부분은 이미 검증된 코드라서요.
- 무대의 **틀 미리보기** 버튼으로 Claude 없이 틀이 도는 모습을 볼 수 있어요.

틀에 기능을 더할수록(예: 효과음, 파티클) Claude가 쓸 코드는 더 줄어듭니다. 단, `GameTemplate.API` 설명이 명령어에 같이 실려 나가니 **설명은 짧게** 유지하세요.

### 2. 저장본 재사용 (`TokenSaver.cache`)

같은 문장 + 같은 빌드 방식 + 같은 모델이면 이 브라우저에 저장된 게임을 그대로 불러옵니다. Claude를 부르지 않으니 **0 토큰**입니다. 최근 12개까지 저장해요. 다른 결과를 원하면 **새로 만들기**를 누르면 돼요.

### 3. 모델 고르기 (`TokenSaver.TIERS`)

- **빠른 모델**: 가볍고 빨라서 사용량이 가장 적어요. 절약 모드와 잘 맞습니다.
- **기본 모델**: 더 꼼꼼하지만 사용량이 더 들어요. 전체 생성 모드에서 결과가 아쉬울 때 쓰세요.

### 4. 출력 길이 제한

명령어에 "100줄 이내, 주석 없이"(절약)나 "250줄 안팎, 주석 없이"(전체)를 넣어 두었습니다. 주석만 빼도 받는 코드가 눈에 띄게 줄어요.

### 5. 사용량 표시

토큰 변환기에 **보내는 명령 / 받을 코드(예상) / 이번 빌드 합계**가 뜨고, 아래에 이 브라우저의 누적 사용량과 저장본으로 아낀 양이 쌓입니다.

## 더 줄이고 싶을 때 손볼 곳

| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 명령어 문구 바꾸기 | `js/token-saver.js` → `buildPrompt()` |
| 예상 출력 토큰 범위 고치기 | `js/token-saver.js` → `MODES[...].expectOut` |
| 틀에 기능 추가 | `js/game-template.js` → `ENGINE`, 그리고 `API` 설명 한 줄 |
| 토크나이저 바꾸기 | `TokenSaver.setCounter(text => 숫자)` |
| 저장 개수 바꾸기 | `js/token-saver.js` → `CACHE_MAX` |

## 쓸 수 있는 오픈 소스

### 토큰 세기

| 이름 | 쓰임 | 주의 |
|---|---|---|
| `@anthropic-ai/tokenizer` (npm) | Anthropic이 공개한 토크나이저 | 예전 Claude 모델 기준이라 최신 모델에서는 **정확하지 않아요.** 어림용으로만 쓰세요. |
| `gpt-tokenizer`, `js-tiktoken` (npm) | 브라우저에서 도는 BPE 토크나이저 | OpenAI 모델용이라 Claude와 값이 다릅니다. 지금 쓰는 어림 계산보다 크게 낫지 않아요. |
| Anthropic **count_tokens API** | 정확한 Claude 토큰 수 | 오픈 소스가 아니라 API입니다. API 키가 필요해서 서버에서 불러야 해요. |

지금 쓰는 한글/영문 어림 계산은 화면에 보여 주는 용도로는 충분합니다. 정확도가 필요해지면 서버를 하나 두고 count_tokens API를 부르는 게 맞아요.

### 프롬프트 압축

| 이름 | 쓰임 | 이 게임에 맞는지 |
|---|---|---|
| **LLMLingua / LLMLingua-2** (Microsoft, Python) | 긴 프롬프트에서 덜 중요한 토큰을 빼서 압축 | 우리 명령어는 500토큰 정도로 이미 짧아서 효과가 작아요. 문서를 통째로 넣는 기능이 생기면 고려해 보세요. |

### 게임 틀 대신 쓸 수 있는 엔진

| 이름 | 장점 | 주의 |
|---|---|---|
| **KAPLAY** (예전 이름 Kaboom.js, MIT) | 몇 줄로 게임을 만들 수 있게 설계된 엔진. Claude가 짧은 코드로 쓸 수 있어요. | CDN에서 불러와야 해서 오프라인 실행이 안 되고, 다운로드한 파일도 인터넷이 필요해요. |
| **Phaser** (MIT) | Claude가 API를 잘 알아서 명령어에 사용법을 길게 안 넣어도 돼요. | 무겁고, 같은 게임도 코드가 길어지는 편이에요. |

지금 쓰는 자체 틀은 의존성이 없어서 **다운로드한 HTML 파일 하나로 오프라인에서도 돌아갑니다.** 그래서 기본값으로 두었어요.

### 코드 압축

| 이름 | 쓰임 | 주의 |
|---|---|---|
| **terser** (JS), **html-minifier-terser** | 받은 코드를 압축해서 파일 크기를 줄임 | 토큰은 Claude가 **쓸 때** 이미 쓰였기 때문에 사용량은 줄지 않아요. 다운로드 파일 크기만 줄어듭니다. |

## 서버를 두게 되면 쓸 수 있는 것 (Claude API 직접 호출)

지금은 Claude Artifact 안에서 보는 사람의 계정으로 Claude를 부르기 때문에 아래 옵션을 직접 설정할 수 없어요. 나중에 서버를 두고 API를 직접 부르게 되면 다음을 쓸 수 있습니다.

- **프롬프트 캐싱**: 매번 똑같은 앞부분(만들기 규칙, 틀 설명)을 캐시해 두면, 다시 읽을 때 입력 단가가 크게 내려가요. 규칙을 명령어 **앞쪽**에, 바뀌는 문장을 **뒤쪽**에 두면 캐시가 잘 맞습니다.
- **`max_tokens`**: 받는 코드 길이에 상한을 걸 수 있어요.
- **Message Batches API**: 바로 받을 필요가 없는 빌드를 모아서 보내면 할인된 가격으로 처리돼요. (예: 미리 인기 조합을 만들어 두기)
- **count_tokens API**: 보내기 전에 정확한 입력 토큰 수를 셀 수 있어요.
