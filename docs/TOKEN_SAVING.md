# 토큰 절약 가이드

게임 한 판에 드는 Claude 사용량은 **보내는 명령(입력 토큰)**과 **받는 답(출력 토큰)**으로 나뉩니다. 이 게임에서는 받는 답(게임 코드)이 훨씬 길어서, 답을 줄이는 게 가장 효과가 큽니다.

> 숫자는 `TokenSaver.count()`의 어림값입니다. Claude 토크나이저는 브라우저용으로 공개돼 있지 않아서, 정확한 값은 Anthropic의 count_tokens API로만 알 수 있어요.

## 빌드 방식별 사용량 (한 판 기준, 어림값)

| 빌드 방식 | 보내는 명령 | 받는 답 | 합계 | 처음 버전 대비 |
|---|---|---|---|---|
| 처음 버전 (HTML 전체) | 약 470 | 약 3,500~6,500 | 약 4,000~7,000 | — |
| 전체 코드 | 약 280 | 약 3,500~6,500 | 약 3,800~6,800 | 입력만 약 40% 감소 |
| 규칙 코드 (틀 사용) | 약 330 | 약 900~1,800 | 약 1,200~2,100 | 약 70% 감소 |
| **설정만 (기본값)** | **약 300** | **약 60~160** | **약 350~450** | **약 90~95% 감소** |
| 0 토큰 | 0 | 0 | **0** | 100% 감소 |
| 심사 탈락 (Claude 모드 공통) | 약 300 | 약 20~40 | 약 320~340 | 거절은 이유 한 줄만 받음 |
| 같은 문장 다시 빌드 | 0 | 0 | **0** | 저장본 재사용 |

## 적용한 방법

### 1. 설정 엔진 + "설정만" 모드 (`js/game-template.js`의 `runGame`, `wrapConfig`)
게임 엔진이 이동 방식 8가지, 행동 8가지, 장애물 패턴 6가지, 닿았을 때 효과 12가지를 미리 갖고 있습니다. Claude는 코드를 한 줄도 안 쓰고, 이 중에서 고른 **JSON 설정 몇 줄**만 돌려줍니다. 받는 답이 수천 토큰에서 100토큰 안팎으로 줄어요.

### 2. 단어 해석표 + "0 토큰" 모드 (`js/word-meta.js`)
카드 단어마다 게임에서 무엇이 되는지 미리 정해 뒀습니다(이모지, 배경색, 이동 방식, 행동, 장애물 패턴, 효과). Claude를 부르지 않고 바로 조립해요. 의미 심사는 없어서 연습용입니다. 해석표에 없는 단어는 기본값으로 조립하고 화면에 알려 줍니다.

### 3. 명령어 압축 (LLMLingua의 아이디어를 손으로 적용)
LLMLingua는 Python 서버에서 도는 도구라 브라우저에서 바로 쓸 수 없습니다. 대신 같은 원리를 명령어에 직접 적용했어요.
- 지시문을 영어로 바꿨습니다. 같은 뜻이면 영어가 한국어보다 토큰이 적게 들어요. 화면에 보이는 글자만 한국어로 달라고 합니다.
- "해석 가이드" 줄을 뺐습니다. 문장에 이미 다 들어 있는 내용이라서요.
- 중복 규칙을 지우고, 틀이 처리하는 규칙은 명령어에서 뺐습니다.

### 4. 거절은 짧게
모든 Claude 모드는 먼저 심사합니다. 말이 안 이어지면 코드를 쓰기 전에 `REJECT: 이유` 한 줄이나 `{"ok":false,"why":...}`만 받습니다. 탈락한 문장에는 토큰이 거의 들지 않아요.

### 5. 저장본 두 겹 (프롬프트 캐싱 대신)
프롬프트 캐싱과 Batch API는 서버에서 API를 직접 부를 때만 쓸 수 있어서 지금 구조에서는 못 씁니다. 대신 두 겹으로 저장합니다.
- **이 브라우저 저장본** (`TokenSaver.cache`): 같은 문장·방식·모델이면 통과든 탈락이든 저장된 결과를 씁니다. 최근 20개.
- **Claude 플랫폼 저장본**: 같은 명령이면 하루 동안 플랫폼이 저장된 답을 돌려줍니다(`cache: {gcTime: 하루}`). 사용량이 들지 않아요. "다시 심사받기"를 누를 때만 새로 물어봅니다.

### 6. 가장 싼 모델이 기본값
"빠른 모델"이 기본입니다. 설정 JSON 정도는 빠른 모델로도 충분해요.

## 적용하지 않은 것과 이유

| 이름 | 이유 |
|---|---|
| `@anthropic-ai/tokenizer`, `gpt-tokenizer`, `js-tiktoken` | 토큰을 **세는** 도구라 사용량을 줄이지는 않습니다. 앞의 것은 예전 Claude 기준이고, 뒤의 둘은 OpenAI용이라 지금 어림 계산보다 크게 정확하지도 않아요. 바꾸려면 `TokenSaver.setCounter()`를 쓰세요. |
| LLMLingua / LLMLingua-2 | Python 서버가 필요합니다. 명령어가 이미 300토큰 정도라 손으로 압축하는 것으로 충분했어요. |
| KAPLAY, Phaser | CDN에서 불러와야 해서 다운로드한 게임이 인터넷 없이 안 돕니다. 자체 설정 엔진이 같은 역할(짧은 입력으로 게임 만들기)을 더 싸게 합니다. |
| terser, html-minifier-terser | 토큰은 Claude가 **쓸 때** 이미 쓰입니다. 받은 뒤 압축하면 파일 크기만 줄고 사용량은 그대로예요. |
| 프롬프트 캐싱, `max_tokens`, Batch API, count_tokens API | 서버에서 API 키로 Claude를 직접 부를 때만 쓸 수 있습니다. 지금은 Artifact 안에서 보는 사람 계정으로 부르는 구조예요. 서버를 두게 되면 규칙 부분을 명령어 앞쪽에 고정하고 문장을 뒤에 두면 캐시가 잘 맞습니다. |
